# سجل دمج المشاريع الثلاثة

هذا المستودع مخصص للاستخدام الشخصي، ويحتوي على ثلاث نسخ مصدرية قبل الدمج ونسخة تشغيل موحّدة لاحقاً. الهدف هو الحفاظ على كل الأقسام والطوابق والوظائف وعدم استبدال أي مشروع بصيغة مبسطة.

## الحالة الحالية

تم استلام ثلاثة ملفات HTML كاملة. الملفان `oracle-legacy` و`oracle-ultimate` متطابقان بايتاً ببايت في النسخة المستلمة، وسيتم الاحتفاظ بهما كمرجعين منفصلين حتى لا تضيع أي نسخة. ملف `market-tower` مختلف ويحتوي على واجهة موسعة تشمل لوحة التحكم والتحليل الفني والمخاطر والأخبار والمحاكيات والمذكرات والأتمتة والتنفيذ السريع.

## سياسة الأسرار

المستودع عام أثناء مرحلة العمل، لذلك لا تُرفع مفاتيح API أو رمز Telegram الحقيقي. النسخ المرفوعة تستخدم علامات مكانية واضحة، بينما تُحفظ النسخ الأصلية محلياً خارج المستودع. بعد جعل المستودع خاصاً، تُضاف الأسرار عبر إعدادات GitHub Secrets ولا تُكتب داخل HTML أو JavaScript.

الأسماء المتوقعة للأسرار هي `FINNHUB_KEY` و`TWELVE_DATA_KEY` و`NEWS_API_KEY` و`FRED_KEY` و`TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID`. يجب تدوير رمز Telegram الذي ظهر في الملفات قبل تفعيله من جديد.

## قواعد الدمج

سيُنفذ الدمج على فرع مستقل، مع إبقاء فروع المصدر كما هي. لن يُحذف أي قسم أو طابق أو وظيفة. عند وجود وظيفتين متشابهتين، تُحفظ النسخة الأصلية في مسارها المرجعي، ويُستخدم محول توافق داخل النسخة المدمجة بدلاً من الحذف أو الاستبدال الصامت.

## تنبيه تشغيلي

الواجهة الحالية تعمل في المتصفح وتستخدم `localStorage` في أجزاء من التتبع. التشغيل المستمر وإصدار التقارير حتى عند إغلاق المتصفح يتطلب عاملاً خلفياً دائماً أو جدولة موثوقة، وسيُضاف ذلك بعد تدقيق محرك الإشارات ومصادر البيانات. لا تُعتبر النتائج توقعاً مضموناً أو توصية استثمارية؛ ستُقاس الإشارات وفق قواعد دخول وخروج وتوقيت معلنة مع فصل النتائج التاريخية عن التقدير المستقبلي.
